## 按独立字段回填

遵循 [字段契约](../references/report-fields.md)：结论 → 分析结论；因果链 → 根因分析；假设/测试/复现 → 排查验证；SHA/工作区 → 代码基线；文件/行号 → 相关代码；候选建议 → 修复方案（未评审）；现场问答 → QA/RD沟通；缺口/恢复条件 → 待核实与阻塞。完整分析保存在此文件和附件，不整份复制到根因分析；修复前排查不写成修复后的验证结果。

## 回填摘要

结论：已确认 / 原因未确认。

已确认时用两到四句说明：触发条件 → 首个错误状态及根因 → 传播路径 → QA 可见现象；附必要的影响范围。
未确认时简述：已验证事实 → 仍成立的假设 → 阻止确认的缺口 → 本轮问题或恢复条件。
关键证据：一到三条可定位的代码、日志、测试或截图引用，注明目标、环境及相关版本。
