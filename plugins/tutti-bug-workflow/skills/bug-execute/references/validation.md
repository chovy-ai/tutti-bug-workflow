# 验证环境

数据目录 `config.json` 的 `validation` 段：

| 键 | 含义 |
|---|---|
| `environment` | 验证环境名，如 PPE 泳道 |
| `url` | 验证地址 |
| `revision_source` | 读取已部署提交的方法，如页面版本信息、健康检查接口或部署平台 |
| `browser_tool` | 使用的浏览器工具：Playwright、浏览器 MCP 或宿主浏览器 |

未配置时按「验收标准」里写的环境执行，并在验证结果中注明。

## 版本核对

1. 按 `revision_source` 读出验证环境实际部署的提交。
2. 确认它包含修复：等于 `pushed_sha`，或在仓库里 `git merge-base --is-ancestor <pushed_sha> <部署提交>` 成立。
3. 读不到版本或不包含修复时，相关用例记 `blocked`，写明恢复条件（例如等待部署到某环境）。

部署只按用户授权的方式进行，不擅自触发部署流水线。

## 证据

- 每条用例至少一份能独立判断结果的证据：截图、接口返回、日志片段或测试输出。
- 截图文件名带用例编号，如 `after-fix-1.png`，上传到「截图、视频、日志」。
- 未执行的用例记 `not_run`，不能写成通过。
